# Ubiquitous Language — Changelog

> Historical record of vocabulary changes. **Not authoritative for current behavior** — the
> three authoritative files are `.agents/ubiquitous-language.md` (product vocabulary),
> `.agents/ubiquitous-language-invariants.md` (every invariant, 1–57) and
> `.agents/ubiquitous-language-scaffold.md` (harness vocabulary, owned by the scaffold).
> Deliberately excluded from `CLAUDE.md`'s import and from the corpus pack (ADR 0016).
> This file carries no `Last updated`: every row is dated, so the last row is the date.
>
> New rows are **one line**: date, what changed, and a pointer to the spec / ADR / issue
> that explains why (decision 7). The essay belongs in the spec, not here.
>
> **Historical rows are verbatim and are never rewritten.** Some of them say
> `settled ahead of implementation` — a convention ADR 0127 abolished by ruling that a term
> enters the glossary when its code lands. Those rows record that the convention *was* used on
> that date; they are not an instruction to use it. No new row may. The authoritative files
> (`.agents/ubiquitous-language.md`, `-invariants.md`, `-scaffold.md`, `-index.md`) must contain
> the phrase nowhere at all; this file is exempt, for exactly this reason. Editing the record
> to satisfy a string check would be the worse failure.
