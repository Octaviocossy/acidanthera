## Goal
Ship v0 of Orbit-111 — a Tauri 2 + React 19 desktop app that edits a local vault of plain `.md` files with a vim-first CodeMirror 6 editor, an Obsidian-style three-region layout driven by a custom app-level vim focus state machine, and an invocable AI chat that renders a normalized `AgentEvent` stream from a headless external-CLI agent (Claude Code, then Codex) — so the full _ask → write note → appears in sidebar → distill_ loop happens in one window. Source spec: `doc/v0-spec.md`.

## Slice summaries (detail lives in each child issue)
- **#2 Foundation (wave 1, root):** the roadmap's _"built first"_ app-level vim focus system — navigation state machine (active region + global mode + chat open/closed) + global keymap + the 3-region layout shell + FAB. Also declares the **entire v0 dependency baseline** and ships **placeholder region components** so siblings only add files.
- **#3 Editor (wave 2):** CodeMirror 6 (`@uiw/react-codemirror`) markdown editor, vim on by default, `Ctrl-w` region-exit at top CM precedence; exposes `editor-store` so #6 can open/save.
- **#4 Filesystem (wave 2):** Rust `notify` watcher + `read_vault_tree`/`read_note`/`write_note` + vault picker; emits `vault-changed`; the data layer for #6.
- **#5 AgentEvent contract (wave 2):** the central `AgentEvent` union + `AgentBackend` interface (pure types); the chat consumes only these.
- **#6 Sidebar loop (wave 3):** collapsible vault explorer; open file → editor, `:w`/`Mod-s` → disk, watcher-driven refresh. Completes Half A.
- **#7 Chat + Claude (wave 3):** invocable chat panel rendering `AgentEvent` (bubbles + tool chips), generic Rust process-spawn, backend registry + selector, Claude Code adapter (`stream-json`). Completes Half B.
- **#8 Codex adapter (wave 4):** second `AgentBackend` (`codex exec --json`) added via the registry with **zero UI changes** — proves adapters are the growth point.

## Architecture invariant (why the waves are conflict-safe)
Foundation (#2) owns `package.json` + `Cargo.toml` + the lockfile and the write-once `Layout.tsx`; every sibling **replaces exactly one placeholder region file** and adds its own scoped CSS/service files. Rust `lib.rs` is extended only by #4 (wave 2) then #7 (wave 3) — sequential, so the `invoke_handler` list never conflicts across parallel branches.
