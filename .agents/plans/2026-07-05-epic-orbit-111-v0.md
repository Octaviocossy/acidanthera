## Goal
Ship v0 of Orbit-111 — a Tauri 2 + React 19 desktop app that edits a local vault of plain `.md` files with a vim-first CodeMirror 6 editor, an Obsidian-style three-region layout driven by a custom app-level vim focus state machine, and an invocable AI chat that renders a normalized `AgentEvent` stream from a headless external-CLI agent (Claude Code, then Codex) — so the full _ask → write note → appears in sidebar → distill_ loop happens in one window. Source spec: `doc/v0-spec.md`.

## Slice summaries (full detail lives in each child issue)
- **#10 Foundation (wave 1, root):** the roadmap's _"built first"_ app-level vim focus system — the navigation state machine (active region + global mode + chat open/closed) + global `Ctrl-w` keymap — plus the whole design-system foundation (Tailwind v4 + shadcn primitives + Orbit tokens + self-hosted JetBrains Mono, dark-only) and the 3-region layout shell + FAB. Owns **every shared artifact** (`package.json`, `Cargo.toml`, lockfiles, `Layout.tsx`, `app-store.ts`) and ships **placeholder region components** so siblings only add files.
- **#11 Editor (wave 2):** CodeMirror 6 (`@uiw/react-codemirror`) markdown editor, vim on by default (`@replit/codemirror-vim`), `Ctrl-w`+`h/j/k/l` region-exit at top CM precedence; in-memory `editor-store` + save-intent so #14 can wire open/save; inline `[[wikilink]]` rendering.
- **#12 Filesystem (wave 2):** Rust `notify` watcher + `pick_vault`/`read_vault_tree`/`read_note`/`write_note` (vault-root-guarded) emitting `vault-changed`; typed `vault.service.ts`. The data layer for #14 and the agent `cwd` for #15.
- **#13 AgentEvent contract (wave 2):** the central `AgentEvent` discriminated union + `AgentBackend` interface + backend registry (pure types); the chat consumes only these.
- **#14 Sidebar loop (wave 3):** collapsible `FileTreeItem` vault explorer; open file → editor, `:w`/`Mod-s` → disk, watcher-driven refresh. Completes Half A.
- **#15 Chat + Claude (wave 3):** invocable chat panel rendering `AgentEvent` (`ChatMessage` + `ToolChip` with `error` status + `ChatInput`), a generic Rust process-spawn, backend registry + selector, Claude Code adapter (`stream-json`). Completes Half B.
- **#16 Codex adapter (wave 4):** second `AgentBackend` (`codex exec --json`) added via the registry with **zero UI changes** — proves adapters are the growth point.

## Architecture invariant (why the waves are conflict-safe)
Foundation (#10) owns `package.json` + `Cargo.toml` + the lockfile, the write-once `src/components/layout/Layout.tsx`, and the app-global `src/stores/app-store.ts` (`vaultRoot`); every sibling **replaces exactly one placeholder region file** and adds its own scoped CSS/service/store files. Rust `src-tauri/src/lib.rs` is extended only by #12 (wave 2) then #15 (wave 3) — sequential across waves, so the `invoke_handler!` list never conflicts on parallel branches. `vaultRoot` lives in the foundation store so the chat slice (#15) reads the agent `cwd` without depending on the sidebar slice (#14).
