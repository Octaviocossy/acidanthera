# Plan: Epic — Adopt the Factory design system

> Status: **completed**
> Created: 2026-07-10
> Updated: 2026-07-10
> Issue: #55

## Goal

Migrate Orbit-111's visual language to **Factory** — a stark dark terminal aesthetic (obsidian
canvas, bone light cards, Geist/Geist Mono two-face type, signal-orange + metric-green functional
accents, flat hairline borders, no shadows). Rewrite the token/font layer once as the foundation,
then restyle each app region on top. Both dark and light themes are kept; dark is Factory-pure and
light is a Factory-derived mirror.

Spec source: `new-system-design-files-to-use/` (`DESIGN.md`, `design-tokens.json`,
`css-variables.css`, `tailwind-v4.css`).

## Decisions (from planning)

- **Theme:** keep dark **and** light. Dark = Factory obsidian; light = Factory-derived mirror.
- **Typography:** adopt **Geist** (body/headings) + **Geist Mono** (labels/eyebrows) as two faces,
  replacing single-face JetBrains Mono.
- **Token names stay stable; only values change** — the layered token system (raw tokens → shadcn
  semantic layer → Tailwind `@theme` utilities) means a re-skin is a values-only edit, which keeps
  the four Wave-2 children on disjoint component files.
- **Accents are functional only:** signal-orange = live/in-flight/status, metric-green =
  positive/done. Never a button or card fill. The retired lime `--fab-accent` is aliased to
  signal-orange for one slice so the chat compiles before it is restyled.
