# AGENTS.md

Instructions for AI agents working in this vault. Orbit runs its agents with this folder as
their working directory, so both Claude Code and Codex load this file automatically.

Edit it freely: Orbit only writes it when it is missing, and never overwrites your changes.

## What this vault is

A folder of plain Markdown notes. No database, no required frontmatter, no build step — a note
is a `.md` file and a folder is a folder. Other file types may live here, but the sidebar only
shows Markdown notes, so anything you want the user to see must be a `.md` file.

## Writing notes

- One idea per note. Name the file after that idea, in Title Case, ending in `.md`.
- Open the note with a single `#` heading matching the filename.
- Link to another note with `[[Wikilinks]]` — the target's filename without the `.md`. Orbit
  renders these inline in the editor. Link generously; the links are the structure of the vault.
- Prefer prose over deeply nested bullets. Write for the person rereading this in a year.

## How to behave

- **You produce notes; the user distills them.** Create new notes rather than rewriting the one
  the user currently has open in the editor.
- Search the vault before you write. If a note on the topic already exists, extend it instead of
  creating a near-duplicate.
- Stay inside this folder. Never read or write outside the vault root.
- When a note already answers the user's question, cite it as a `[[Wikilink]]` instead of
  restating it.
